# **App Name**: DropNDry

## Core Features:

- User Authentication: Secure login/signup functionality for users, vendors, and admin.
- Location Detection: Automatically detect user location or allow manual location selection to find nearby laundry shops.
- Laundry Shop Listings: Display nearby laundry shops with details like name, distance, services, price list, and ratings.
- Order Placement: Allow users to select a laundry shop, choose services, select pickup & delivery time, and place an order.
- Order Tracking: Provide real-time order tracking with status updates (Order placed, Pickup scheduled, In process, Out for delivery, Delivered).
- Vendor Dashboard: Enable vendors to manage their profile, services, prices, and order status.
- Admin Dashboard: Provide an admin interface to manage users, vendors, orders, and analytics.

## Style Guidelines:

- Primary color: Teal (#008080) to give a clean and refreshing look, drawing inspiration from water and cleanliness associated with laundry.
- Background color: Very light teal (#E0F8F8), a desaturated variant of the primary color to ensure comfortable contrast.
- Accent color: Yellow-Green (#9ACD32), an analogous color to teal, but different in brightness and saturation, to give calls to action more emphasis.
- Body and headline font: 'PT Sans', a humanist sans-serif to provide a modern yet friendly and readable text.
- Use clean, modern icons to represent laundry services and order status, complementing the app's logo and color scheme.
- Mobile-first responsive design with clean cards and smooth navigation, similar to Swiggy/Zomato.
- Subtle animations and transitions for order updates and UI interactions to enhance user experience.
